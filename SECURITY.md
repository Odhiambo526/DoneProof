# Security

DoneProof is an assurance system and should be deployed with evidence credentials separated from the execution agent whenever possible.

The security model, trust boundaries, receipt integrity design and known pilot limitations are documented in [docs/SECURITY.md](docs/SECURITY.md).

For vulnerabilities in a private deployment, use the deployment owner's established security reporting channel. For this repository, prefer GitHub's private security-advisory workflow rather than filing sensitive details in a public issue.
