# Changelog

- Added server-registered high-assurance run lifecycle.
- Added Gmail verification with sent-vs-draft and attachment/recipient metadata.
- Added HMAC-authenticated enterprise webhook evidence ingestion and replay protection.
- Added tenant/API-key isolation.

- Added receipt integrity endpoint and human-readable certificates.
- Added idempotent verification requests.
- Added transient provider retry behavior and verification timeouts.
- Added secret redaction and conservative customer-facing error messages.
- Added production readiness checks and security response headers.
- Added assurance console, capabilities API and pilot documentation.
- Expanded adversarial and integration test coverage.
